CoolShades

A beautiful color shade generator for designers and developers built-in eyedropper tool. Built with Tauri and React.

## Features

- Generate color shades
- Built-in eyedropper tool
- Cross-platform
- Open source

## Installation

```bash
# Clone the repository
git clone https://github.com/geprakoso/coolshades.git

# Navigate to the project directory
cd coolshades

# Install dependencies
npm install

# Run the application
npm run dev
```

## Usage

```bash
# Run the application
npm run dev
```
